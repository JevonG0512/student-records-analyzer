# Student Records Analyzer

A Java console application that ingests, stores, and analyzes student academic records from file input using object-oriented data structures.

## Features
- Upload student records (name, major, exam grades) from a text file
- View all uploaded student data
- Search for students by major
- Generate a statistics report: grade averages with letter grades, students sorted alphabetically by first name, and the highest/lowest individual grades
- Print the generated statistics file back to the console

## Built With
- Java
- File I/O (reading structured input, writing formatted reports)
- ArrayList-based data modeling
- Sorting and search algorithms

## How to Run
1. Clone the repo
2. Compile: `javac StudentWorker.java`
3. Run: `java StudentWorker`
4. Choose option 1 to upload data from a file, then explore the other menu options
